From a repository checkout, use Python 3.10 or newer. On Windows, enable UTF-8 mode first with $env:PYTHONUTF8='1' in PowerShell.

python -m pip install -r releases/v2.1/requirements.txt
python -B releases/v2.1/verify_all.py --output-dir verification-output

Synthetic fixtures use a declared replay time. Historical validity never restores live permission. Store new verification evidence outside the immutable package.

Evidence, reuse and version history

MHIOS's semantic master is Markdown; Word, PDF and HTML are reading projections. The Core owns its governing semantics. The Apache-2.0 license permits use, modification and redistribution under its terms; retain notices and identify changes.

License · Citation · Contribute

The prior public GitHub edition was v0.8. This supplied v2.1 edition records a v2.0 source baseline and requires explicit migration; old records cannot simply be relabeled. The historical release remains available.

The package does not establish empirical effectiveness, M2/M3 deployed-interface conformance, complete external Canon integration, native Excel interoperability, lawful authority, physical safety or production readiness. Manual and implementation-specific obligations remain visible in its coverage register.
