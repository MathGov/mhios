# Security and claim scope

This repository publishes a read-only research checker and static reading site, not an operational authorization service. Never treat its success output as permission to execute.

For a vulnerability involving data exposure or an unsafe implementation path, contact james@ripplelogic.org without publishing secrets or personal records. Include version, affected code and a synthetic reproduction. Ordinary reproducible research issues can use GitHub Issues. No guaranteed response time or independent security certification is claimed.
