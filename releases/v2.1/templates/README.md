# Preparation templates

The workbook is a manual preparation aid with 20 local status-projection formulas, not a Canon calculator or authorization service. `TOKENS_QUALIFY` tests declared status strings and the presence of a reference, not evidence truth. Source documents, criteria for `NOT_MATERIAL` / `NOT_TRIGGERED`, controls, human review and actual authority remain separate.

The YAML draft is deliberately incomplete and must not pass the completed-session schema untouched. Keep draft artifacts separate from reviewed records. Fill per-option fields, attach the actual source records, declare material unknowns and run the read-only validator. Do not copy the synthetic examples into an observed claim.

M0–M3 is a target level, not achieved conformance. Checkbox entries and record references do not certify accessibility, runtime controls or independent review.
