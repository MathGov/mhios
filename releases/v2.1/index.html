What this package does

MHIOS makes decision evidence, uncertainty, qualification, responsibility and next actions visible. Its local checker tests declared record consistency. It cannot create evidence, evaluate sentience, authorize actions or certify a deployment.

Reading and scoped testing release. No operational dashboard or autonomous runtime is deployed here. Core equations and all fifteen supplied Core files are unchanged.
