# MHIOS v0.8 Implementation Roadmap

1. Maintain the self-assessment, normative coverage, object-justification, and mutation reports.
2. Build the 12-core-object, five-screen no-AI minimal vertical slice for one Tier 2 retrospective case, with a separately typed `ComputationalClosureRecord` generated during review/export.
3. Put the slice before 6-10 representative reviewers and publish what breaks.
4. Revise or remove requirements that do not earn their burden.
5. Run the preregistered 20-reviewer, 8-10-case agreement and comparator study.
6. Add conditional objects and anti-theater sampling only for demonstrated failure modes.
7. Add optional AI only after a no-AI baseline, using independent-first-pass and AI-off comparisons.
8. Before any execution-capable prototype, implement the v0.8 mandate-currency and successor-integrity contract, canonical mandate snapshots, negative authorization vectors, fail-state behavior, and independent replay. Do not infer legal validity from schema or validator passage.
9. Consider v1.0 maturity and Core inclusion only after usable, reproducible, institutionally supported evidence exists.
