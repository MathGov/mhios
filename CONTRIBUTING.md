# Contributing

Report the exact release, source section or file, expected behavior, observed behavior and smallest reproducible example. Use synthetic or appropriately redacted records; do not post private stakeholder data or credentials.

Keep research arguments, software failures, accessibility findings and operational evidence distinct. A passing local validator is not authority. Changes to the frozen publication require a new edition with regenerated documents, checksums and tests; do not patch its files in place. Repository navigation and CI changes can be reviewed separately. Contributions must be yours to share and retain applicable notices.
